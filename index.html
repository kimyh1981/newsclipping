들을 언론사 고르기

고른 언론사는 이 기기에만 저장돼요. 갤럭시 앱은 앱의 '들을 언론사'에서 따로 고릅니다. 외국 언론은 제목을 우리말로 번역해 읽어요.

아이폰 단축어용 코드: 단축어의 '텍스트' 칸에 붙여 넣으면 여기서 고른 언론사만 읽어요.

차에 타면 자동으로 듣기

평일 아침 6~8시, 차 블루투스가 연결되면 오늘의 헤드라인을 읽어 줍니다. 주말·공휴일은 쉽니다.

갤럭시 (안드로이드)

뉴스클리핑 앱 받기 (APK)
  1. 받은 파일을 열고 설치를 누릅니다. '출처를 알 수 없는 앱' 경고가 나오면 이 브라우저에 허용을 한 번 켭니다 (플레이스토어 앱이 아니어서 나오는 안내입니다).
  2. 앱을 열고 화면 순서대로 권한 허용 → 배터리 제한 없음 → 차 블루투스 선택을 누릅니다.
  3. 끝. 앱을 닫아도 차 블루투스가 연결되면 읽기 시작하고, 끊기면 멈춥니다.

아이폰

'뉴스클리핑' 단축어 추가

  1. 위 버튼으로 단축어를 추가합니다 (버튼이 없으면 아래 '단축어 직접 만들기'대로).
  2. 위 '들을 언론사 고르기'에서 언론사를 고르고 아이폰 단축어용 코드를 복사해, 단축어의 텍스트 칸에 붙여 넣습니다. 언론사를 바꾸면 코드도 다시 붙여 넣습니다.
  3. 단축어 앱 → 자동화 → + → 블루투스 → 차 블루투스 선택 → 연결될 때, 즉시 실행 → 단축어 '뉴스클리핑'을 고릅니다.
단축어 직접 만들기
  1. 단축어 앱 → + → 이름 '뉴스클리핑'
  2. 현재 날짜 → 날짜 형식 지정 (사용자 지정 H) → 만약 형식이 지정된 날짜가 6과 7 사이
  3. 만약 안에: 텍스트 (위 코드를 붙여 넣기) → 텍스트 분할 (공백 기준)
  4. 각 항목을 반복 안에: URL https://kimyh1981.github.io/newsclipping/ios/반복 항목.txt → URL의 콘텐츠 가져오기 → 텍스트 말하기 (한국어, Siri 음성)

아이폰은 앱이 블루투스 연결을 알아차리는 것을 허용하지 않아, 자동화 연결만 직접 한 번 해야 합니다. 언론사마다 따로 읽어서, 같은 사건이 두 언론사에 다 나오면 두 번 들릴 수 있어요.
