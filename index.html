뉴스클리핑

불러오는 중…

차에 타면 자동으로 듣기

평일 아침 6~8시, 차 블루투스가 연결되면 오늘의 헤드라인을 읽어 줍니다. 주말·공휴일은 쉽니다.

갤럭시 (안드로이드)

뉴스클리핑 앱 받기 (APK)
  1. 받은 파일을 열고 설치를 누릅니다. '출처를 알 수 없는 앱' 경고가 나오면 이 브라우저에 허용을 한 번 켭니다 (플레이스토어 앱이 아니어서 나오는 안내입니다).
  2. 앱을 열고 화면 순서대로 권한 허용 → 배터리 제한 없음 → 차 블루투스 선택을 누릅니다.
  3. 끝. 앱을 닫아도 차 블루투스가 연결되면 읽기 시작하고, 끊기면 멈춥니다.

아이폰

'뉴스클리핑' 단축어 추가

  1. 위 버튼으로 단축어를 추가합니다.
  2. 단축어 앱 → 자동화 → + → 블루투스 → 차 블루투스 선택 → 연결될 때, 즉시 실행 → 단축어 '뉴스클리핑'을 고릅니다.

아이폰은 앱이 블루투스 연결을 알아차리는 것을 허용하지 않아, 2번(자동화 연결)만 직접 한 번 해야 합니다.
