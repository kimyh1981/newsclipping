들을 언론사 고르기

고른 언론사는 이 기기에만 저장돼요. 갤럭시 앱은 앱의 '들을 언론사'에서 따로 고릅니다. 외국 언론은 제목을 우리말로 번역해 읽어요.

아이폰 단축어용 코드: 단축어의 '텍스트' 칸에 붙여 넣으면 여기서 고른 언론사만 읽어요.

차에 타면 자동으로 듣기

평일 아침 6~8시, 차 블루투스가 연결되면 오늘의 헤드라인을 읽어 줍니다. 주말·공휴일은 쉽니다.

갤럭시 (안드로이드)

뉴스클리핑 앱 받기 (APK)
  1. 받은 파일을 열고 설치를 누릅니다. '출처를 알 수 없는 앱' 경고가 나오면 이 브라우저에 허용을 한 번 켭니다 (플레이스토어 앱이 아니어서 나오는 안내입니다).
  2. 앱을 열고 화면 순서대로 권한 허용 → 배터리 제한 없음 → 차 블루투스 선택을 누릅니다.
  3. 끝. 앱을 닫아도 차 블루투스가 연결되면 읽기 시작하고, 끊기면 멈춥니다.

아이폰

  1. 사파리에서 이 화면을 열고 공유 → 홈 화면에 추가를 누릅니다 (기사를 보며 들을 때 씁니다).
  2. 단축어 앱 → 자동화 → + → 블루투스 → 차 블루투스 선택 → 연결될 때, 즉시 실행 → 새로운 빈 자동화 → 동작 URL 열기에 https://kimyh1981.github.io/newsclipping/?car 를 넣습니다.
  3. 끝. 평일 아침 6~8시에 차에 연결되면 큰 '눌러서 듣기' 화면이 뜹니다. 한 번 누르면 자연스러운 녹음 음성과 자막으로 끝까지 읽습니다 (사파리는 사람이 한 번 눌러야 소리를 낼 수 있습니다).
누르지 않고 듣기 (Siri 음성, 단축어 동작 3개)

'뉴스클리핑' 단축어 추가

  1. 위 버튼으로 단축어를 추가하거나, 직접 만듭니다: 단축어 앱 → + → 이름 '뉴스클리핑'
  2. URL: https://kimyh1981.github.io/newsclipping/ios/at/를 쓰고, 키보드 위 변수에서 현재 날짜를 넣은 뒤 그 변수를 눌러 날짜 형식 사용자 지정 H로 바꾸고, 이어서 .txt를 씁니다.
  3. URL의 콘텐츠 가져오기 → 텍스트 말하기 (언어 한국어, Siri 음성이 가장 자연스럽습니다)
  4. 자동화의 동작으로 'URL 열기' 대신 단축어 실행 → '뉴스클리핑'을 고릅니다. 6~8시가 아니거나 쉬는 날에는 아무것도 읽지 않습니다.
언론사 골라 듣기 (고급)
  1. 단축어 앱 → + → 이름 '뉴스클리핑'
  2. 현재 날짜 → 날짜 형식 지정 (사용자 지정 H) → 만약 형식이 지정된 날짜가 6과 7 사이
  3. 만약 안에: 텍스트 (위 '아이폰 단축어용 코드'를 붙여 넣기) → 텍스트 분할 (공백 기준)
  4. 각 항목을 반복 안에: URL https://kimyh1981.github.io/newsclipping/ios/반복 항목.txt → URL의 콘텐츠 가져오기 → 텍스트 말하기 (한국어, Siri 음성)

아이폰은 앱이 블루투스 연결을 알아차리는 것을 허용하지 않아, 자동화 연결만 직접 한 번 해야 합니다 (Apple이 자동화는 링크로 나눌 수 없게 막아 두었습니다).
